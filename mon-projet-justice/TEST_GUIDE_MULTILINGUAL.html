Résumé des Modifications

1. Fonction Décodeur de Langue

Fichier: src/App.tsx

Mappe plus de 30 langues à leurs codes BCP 47 pour une lecture audio native du navigateur.

function getLanguageCode(language?: string): string { const languageMap = { 'arabic': 'ar-SA', 'english': 'en-US', 'spanish': 'es-ES', 'french': 'fr-CA', // ... 26 autres langues } }

2. Traduction du Plan d'Action

Fichier: src/lib/openJustice.ts

Traduit automatiquement les étapes du plan d'action basé sur la langue maternelle de l'utilisateur.

export function translateActionPlan( actionPlan: ActionPlan, language?: string ): ActionPlan

3. Intégration en StepActionPlan

Le composant reçoit la langue de l'utilisateur et:

  • Traduit le plan d'action
  • Passe le code de langue correct à TextToSpeech
  • Active l'audio natif dans la langue maternelle

Scénarios de Test

Scénario 1: Réfugié parlant Arabe

Profil Utilisateur:

  • Âge: 32 ans
  • Pays d'origine: Syrie
  • Statut migratoire: Demandeur d'asile
  • Langue maternelle: arabe
  • Problèmes juridiques: Immigration, Logement

Résultats Attendus:

Plan d'action traduit en arabe
Audio natif en arabe saoudien (ar-SA)
Titre: "تقديم طلب الحماية" (Soumettre demande de protection)
Description complète en arabe

À Tester: Cliquez sur [LISTEN] Écouter et écoutez le plan d'action se lire en arabe natif

  • Problèmes juridiques: Emploi

Résultats Attendus:

Plan d'action traduit en espagnol
Titre: "Verificar estado laboral" (Vérifier statut de travail)

Architecture du Flux Multilingue

UserProfile.primary_language
↓
App.tsx → StepActionPlan (prop userLanguage)
↓
getLanguageCode(userLanguage) → "ar-SA", "es-ES", etc.
↓
translateActionPlan(actionPlan, userLanguage)
↓
TextToSpeech language={languageCode}
↓
SpeechSynthesisUtterance.lang = languageCode
↓
Audio natif dans la langue de l'utilisateur

Instructions de Démonstration pour le Hackathon

Avant la Présentation

  • Build du projet réussie: npm run build
  • Application démarre: npm run dev
  • Tester avec langue = "arabic" → arabe affiché
  • Tester audio "Écouter" → son en arabe
  • Tester avec "english" → anglais affiché
  • Tester avec "french" → français affiché

Pendant la Présentation (2-3 minutes)

Montrer le code de mappage des langues (15 sec)
Montrer un utilisateur arabophone recevant des conseils en arabe (30 sec)
Cliquer "Écouter" et laisser l'audio se jouer en arabe (30 sec)
Montrer la scalabilité (ajouter une nouvelle langue = 5 min) (30 sec)
Montrer un deuxième utilisateur en anglais/espagnol (30 sec)

Points de Démonstration Clés

Accessibilité "Notre app parle la langue maternelle de l'utilisateur"

Scalabilité "Support de 30+ langues avec un mapping simple"

Juridique + Tech "Plans d'action traduits + audio natif = accessibilité complète"

Zero Data "Web Speech API natif du navigateur = zéro appel API de traduction"
